# 교대달력 플러스 — Play 데이터 보안 양식 답변 초안

| 질문 | 답변 |
|---|---|
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | 아니요 |
| 모든 사용자 데이터가 전송 중 암호화되나요? | 해당 없음(사용자 데이터 전송 없음). 앱 자체는 HTTPS(apps.qaplus.kr)로 제공 |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 해당 없음(운영자 보관 데이터 없음). 앱 설정 → "모든 기록 삭제"로 기기 내 데이터 즉시 삭제 가능 |
| 계정 생성 | 없음 |
| 광고 ID 사용 | 없음 |

## 데이터 유형별
- 위치, 개인 정보, 금융 정보, 건강·피트니스, 메시지, 사진·동영상, 오디오, 파일·문서, 캘린더, 연락처, 앱 활동, 웹 탐색, 앱 정보·성능, 기기 ID: **모두 수집·공유 안 함**

## 참고 메모 (제출 시 판단 근거)
- 근무 기록·메모·시급 설정은 기기 localStorage에만 저장되며 개발자 서버로 전송되지 않습니다. Google 정의상 "기기 밖으로 전송되지 않는 데이터"는 수집으로 보지 않습니다.
- 백업 JSON 파일은 사용자가 직접 저장·선택하며 앱이 외부로 보내지 않습니다.
- 화면 글꼴을 공개 CDN(cdn.jsdelivr.net)에서 받습니다. 개발자가 해당 요청 정보를 수집·이용하지 않으므로 "수집 없음"으로 답하되, 개인정보처리방침 5항에 고지했습니다. [확인 필요: 엄격하게 보려면 글꼴을 앱 폴더에 자체 포함하는 방식으로 바꾸면 외부 요청이 0건이 됩니다]
- 사용 권한: Android 위험 권한 없음(TWA 기본 INTERNET만).
